  250 +/* The data type a JSON index extracted its values as, before handing them to
  251 + * the target index.
  252 + *
  253 + * A JSON value has no fixed type, so a JSON index decodes the value at its path
  254 + * into a single Arrow type and trains the target index on that. The supported
  255 + * variants map from the JSONB type tags: a JSON boolean becomes BOOLEAN, a
  256 + * JSON integer INT64, a JSON float FLOAT64, and a JSON string UTF8.
  257 + */
  258 +enum JsonTargetDataType {
  259 +  /* The type this index was trained on is not recorded here. An index built
  260 +   * before this field existed carries UNSPECIFIED, and so does one whose type
  261 +   * a later rewrite of these details could not recover.
  262 +   *
  263 +   * A reader that needs the type must first ask the target index: some target
  264 +   * types retain the Arrow type they were trained on, and that answer is
  265 +   * authoritative. Only a target that cannot report one leaves the type to be
  266 +   * inferred by decoding the data again, reading the type tag of the first
  267 +   * non-null value at the path and falling back to UTF8 when every value is
  268 +   * null. Inference depends on which rows are read -- inferring over a
  269 +   * different row set, or over disjoint subsets in separate workers, can
  270 +   * produce a different type than the original index -- which is the
  271 +   * inconsistency this field exists to prevent, so it is the last resort
  272 +   * rather than the defined behavior for UNSPECIFIED.
  273 +   *
  274 +   * Because UNSPECIFIED records no type, there is nothing for a rewrite to
  275 +   * preserve, and it is the one value the preservation rule on field 3 does
  276 +   * not cover: an implementation rewriting these details may replace
  277 +   * UNSPECIFIED with a type it recovered authoritatively, and should, so the
  278 +   * index stops being ambiguous. It must not replace it with an inferred type,
  279 +   * which would persist a row-dependent guess as though it were recorded fact.
  280 +   *
  281 +   * A build that understands this field always records it when training a new
  282 +   * index, so UNSPECIFIED is only ever a legacy or unrecoverable state.
  283 +   */
  284 +  JSON_TARGET_DATA_TYPE_UNSPECIFIED = 0;
  285 +  JSON_TARGET_DATA_TYPE_BOOLEAN = 1;
  286 +  JSON_TARGET_DATA_TYPE_INT64 = 2;
  287 +  JSON_TARGET_DATA_TYPE_FLOAT64 = 3;
  288 +  JSON_TARGET_DATA_TYPE_UTF8 = 4;
  289 +  /* Deprecated. A JSON array or object, stored as its re-serialized JSONB
  290 +   * value. No query can be served by an index of this type, so writers should
  291 +   * not produce it, and future versions may reject it at index creation.
  292 +   */
  293 +  JSON_TARGET_DATA_TYPE_LARGE_BINARY = 5;
  294 +}
