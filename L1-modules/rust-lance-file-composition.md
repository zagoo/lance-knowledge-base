## Physical mapping and external metadata

V2_0 emits every ordinary field/header before its descendants; Blob/packed fields are opaque one-column units. V2_1+ emits only leaves and opaque units; ordinary containers contribute no separate header. Empty structs count as leaves. Both traversals preserve field order, retain field IDs, use recursive traversal and an unchecked signed i32 column counter. BTreeMap construction collapses duplicate IDs and casts negative field IDs; shared structural mapping filters negative column indices, while V2_0 does not. None of these functions validates schema correctness. (rust/lance-file/src/versions/v2_0/mod.rs:38-82; rust/lance-file/src/reader/structural.rs:173-224)

V2_0 external metadata locates a column by the same header-inclusive traversal, classifying a target as header when logical_type.is_struct and not packed. Skip copying a recognized header if pages already exist. Finalization keeps only first header page, overwrites its num_rows with total and priority with zero, and retains its encoding/buffer descriptors. Empty pages and missing column targets are no-ops; missing target is treated as nonheader rather than a bounds error. This is metadata normalization, not data copying. (rust/lance-file/src/versions/v2_0/mod.rs:84-132)

## Compression selection and parameter precedence

Policy owns tuning maps. Effective params merge datatype-string configuration, then exact column name or the first matching HashMap pattern, then non-None field metadata values. Local field.name is used, not a synthesized qualified path. Overlapping patterns do not acquire deterministic ordering here. V2_1 clears only metadata minichunk_size >=32768 and logs; a configured base value can remain, including a large value. Negative/zero values are not rejected by that wrapper. V2_2/V2_3 do not have this guard. (rust/lance-encoding/src/compression_config.rs:85-140; rust/lance-file/src/versions/v2_1/compression.rs:29-46; rust/lance-file/src/versions/v2_2/compression.rs:32-38; rust/lance-file/src/versions/v2_3/compression.rs:32-38)

All three miniblock cascades are: explicit uncompressed fixed width; byte-stream split; version RLE; bitpacking; raw fixed width; variable width; fixed packed struct; raw fixed-size-list; NotSupported. V2_1/V2_2 use fixed-u8 RLE; V2_3 uses child RLE. Successful selection then calls finalize_miniblock_compressor, which can fail. The inspected finalizer wraps FixedWidth with requested general compression and otherwise preserves the chosen compressor; codec implementation remains pending. (rust/lance-file/src/versions/v2_1/compression.rs:49-83; rust/lance-file/src/versions/v2_2/compression.rs:41-75; rust/lance-file/src/versions/v2_3/compression.rs:41-77; rust/lance-encoding/src/compression.rs:593-613)

|---|---|---|
| V2_1 | raw; rejecting packed helper; variable width | bitpacking; raw; computed params unused |

## Structural syntax, validation and memory

fetch_encoding rejects indirect and absent locations, clones Direct payload, decodes prost Any, then checks/decodes requested message type. Page syntax fetches pb21::PageLayout; column syntax fetches pb::ColumnEncoding. Exact reader grammar validation must happen separately. Page construction checks equal offset/size counts and every offset divisible by64; global buffers check positions divisible by64; column descriptor pairs check count equality but not alignment. None of these helpers checks size, overlap or offset+size/file bounds. Supplied PageLayout/page_infos are trusted inputs at these normalization boundaries. (rust/lance-file/src/reader/structural.rs:29-171; rust/lance-file/src/writer.rs:23-24)

Normalized page descriptors/pages are moved into Arc slices; ColumnInfo itself is Arc-owned. Temporary pairing allocations drop on error. Direct encoding bytes are cloned before protobuf decode. This is metadata memory ownership, not zero-copy materialization of data arrays. (rust/lance-file/src/reader/structural.rs:35-45; rust/lance-file/src/reader/structural.rs:92-154)

## Projection and logical length

Projection by IDs silently omits unmapped physical fields while cloning the entire requested Schema; it neither prunes the schema nor rejects duplicate indices. Projection by names delegates schema.project before ID mapping. Downstream consistency checks are therefore essential. Physical schema traversal order is the decoder index order. (rust/lance-file/src/reader/structural.rs:226-272)

The recursive length walker consumes one supplied index per leaf/opaque field and errors if too few; projection_length rejects leftovers. Ordinary struct children must agree only while comparable remains true. A nonstruct container sets it false for all descendants, so deeper structs do not reenable comparison. Containers take their first child's reported length; no FSL multiply/divide occurs here. All top-level field lengths must agree; an empty projection with no indices yields zero at this helper layer. Other caller validation can reject empty projections. (rust/lance-file/src/reader/structural.rs:274-357; rust/lance-file/src/reader.rs:555-569)

Physical-column length sums normalized page rows with checked u64 addition. Sparse first structural layer num_slots supplies page length when present; other cases use PageInfo.num_rows. Overflow returns InvalidInput. The complete shared reader is now covered in the [shared reader supplement](rust-lance-file-shared-reader.md), including raw versus normalized row counts. (rust/lance-file/src/reader.rs:539-553)

A StructuralReadProjection stores the exact version DecodeColumn function pointer. Full metadata preparation validates then clones metadata/projection; indexed preparation validates eligible shape, awaits selected column metadata through IO/cache, and compacts decoder indices to0..N with same schema Arc. It computes length only after loading/preparing, so IO/cache work may precede a length error. No rollback or explicit cancellation guard is added here. Indexed eligibility's inspected helper excludes Blob/packed fields and uses checked descendant counts. Exact grammar is covered in the reader supplement; shared-reader cache loading is covered separately; delegated decoder/IO scheduler lifetimes remain pending. (rust/lance-file/src/reader/structural.rs:359-432; rust/lance-file/src/reader.rs:512-532)
