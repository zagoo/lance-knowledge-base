## Ownership and initialization

Each public concrete Writer privately owns a StructuralFileSink, EncodingPipeline and CompressionParams. Its exact parent supplies encoding_strategy; the shared components do not select a version. Eager construction creates the same lazy object and initializes it before returning. Lazy construction only stores inputs. Initialization validates explicit options, computes runtime encoding options, validates schema, constructs BatchEncoder, then moves its encoders/mapping into the pipeline and initializes sink columns. The first write_batch infers a missing schema from Arrow, including for an empty batch. write_column only requires an already stored schema; it never infers one from a bare array. (rust/lance-file/src/versions/v2_1/writer.rs:27-123; rust/lance-file/src/versions/v2_2/writer.rs:27-123; rust/lance-file/src/versions/v2_3/writer.rs:27-123; rust/lance-file/src/writer/structural.rs:442-458; rust/lance-file/src/writer/structural.rs:652-683)

```text
exact Writer
|-- CompressionParams -> exact field/page/compression strategy
|-- EncodingPipeline
|   |-- schema + ExpectedTypes + schema metadata
|   |-- field encoders + field-ID/physical-column mapping
|   '-- per-field row counts + maximum/aggregate row count
'-- StructuralFileSink
    |-- ObjectWriter + column metadata + user-global descriptors
    '-- optional page spill: Pending -> Active sidecar/chunk lists
```

These are ordinary owned fields with no local mutex, task spawn or Drop implementation. Both sink and pipeline expose crate-internal mechanisms that assume the wrapper maintains their relationship; they do not encode lifecycle state in the type system. (rust/lance-file/src/writer/structural.rs:50-58; rust/lance-file/src/writer/structural.rs:132-177; rust/lance-file/src/writer/structural.rs:381-455; rust/lance-file/src/versions/v2_1/writer.rs:32-36)

## Runtime options and validation

| Input | Actual local resolution |
|---|---|
| data_cache_bytes absent | 8 MiB per top-level field |
| data_cache_bytes present | integer division by top-level schema field count; remainder dropped |
| max_page_bytes present | supplied value; explicit Some(0) rejected before initialization |
| max_page_bytes absent | parse LANCE_FILE_WRITER_MAX_PAGE_BYTES as untrimmed u64; otherwise 32 MiB |
| invalid environment value | warning and 32 MiB; missing/non-Unicode value silently uses default |
| environment value 0 | accepted by this resolver; it is outside explicit-option validation |
| keep_original_array absent | false, distinct from EncodingOptions::default's true |
| buffer_alignment | 64 bytes |

The budget is divided by logical top-level fields even though one field may map to multiple physical columns. A supplied cache budget and zero top-level fields divide by zero before the wrapper reaches schema.validate. These are local formulas, not measured peak-memory bounds. (rust/lance-file/src/writer/structural.rs:410-439; rust/lance-file/src/writer.rs:56-65; rust/lance-file/src/versions/v2_1/writer.rs:78-84; rust/lance-encoding/src/encoder.rs:277-285; rust/lance-encoding/src/encoder.rs:332-365)

ExpectedTypes validates written fields by name, and encode_batch also selects by name; nullability instead zips batch columns against schema fields positionally. A reordered batch can therefore have nulls judged against another field's nullable flag. Recursive validation uses logical_nulls, intersects struct validity with inherited reachability, and ignores child nulls under a null struct parent. Nonstruct child-data recursion resets reachability and checks all exposed child slots; zip does not enforce equal child counts. (rust/lance-file/src/writer/field_types.rs:87-128; rust/lance-file/src/writer/structural.rs:461-543; rust/lance-file/src/writer/structural.rs:570-595)

## Batch and column mutation order

For write_batch: verify types/nullability; return for zero rows; reject a single batch longer than u32::MAX; collect all name-selected fields; call each encoder with its old field row number and a fresh RepDefBuilder; write out-of-line buffers; check aggregate u64 addition; advance every field counter and aggregate; await ordered page tasks and writer flush. The overflow check is after encoder mutation and possible buffer writes. A page or flush error leaves counters advanced. There is no rollback transaction around the batch. (rust/lance-file/src/writer/structural.rs:546-650)

write_column checks schema/index and the single array's u32 limit, then type/nullability and empty input. It encodes only that field, writes external buffers, performs unchecked per-field addition, and updates aggregate rows with max before awaiting pages. Unequal field lengths are supported locally; finish does not require equality. A contextual test writes lengths five and one, then expects a single-column projection to read one row and a joint projection to fail. That test covers V2_0/V2_1 and has not been executed here. (rust/lance-file/src/writer/structural.rs:652-703; rust/lance-file/src/writer/structural.rs:725-801; rust/lance-file/src/writer_tests.rs:1084-1176)

FuturesOrdered preserves task output order; the sink writes one returned page at a time and stops at the first task/page error. Dropping remaining futures is visible here, but cancellation of any work they may have spawned is not established. The final flush comment describes observing already-failed uploads without waiting for all in-flight uploads; backend durability remains outside this analyzed scope. (rust/lance-file/src/writer/structural.rs:247-259)

## Alignment and metadata boundaries

Ordinary page, batch external, column and user-global buffers receive trailing padding of byte 0x48 to round their **length** to 64. This does not repair a misaligned starting position. write_external_buffer instead inserts leading zero padding based on current position and writes payload without trailing padding. Its returned start is aligned, but its end can leave the next ordinary buffer misaligned. Descriptors record payload lengths excluding padding. (rust/lance-file/src/writer/structural.rs:41-45; rust/lance-file/src/writer/structural.rs:187-229; rust/lance-file/src/writer/structural.rs:262-284; rust/lance-file/src/writer/structural.rs:352-360)

Two finish-path assumptions are explicit in the source. First, finish_encoders writes out-of-line buffers raw, while the planner advances virtual positions by payload plus padding without modifying the payload. Second, column-buffer recording advances a local position by payload length while actual writes include trailing padding. Producers supplying multiple unaligned buffers would violate these recorded-position assumptions. This is a source-level deduction, not a reproduced failure or a claim that current producers emit that shape. (rust/lance-file/src/writer/structural.rs:725-765; rust/lance-encoding/src/encoder.rs:130-159)

Page metadata is constructed after its payload IO. Both Legacy and Structural descriptions are Any-wrapped into Direct encoding without exact grammar validation; length is encoded_page.num_rows and priority is row_number. The version reader later owns grammar acceptance. External metadata initialization replaces sink metadata and pipeline schema/declared rows without validating or resetting encoders, mapping, expected types or field counters. This path requires coherent caller-managed state. (rust/lance-file/src/writer/structural.rs:179-185; rust/lance-file/src/writer/structural.rs:206-244; rust/lance-file/src/writer/structural.rs:783-788; rust/lance-file/src/versions/v2_1/writer.rs:135-145)

## Page metadata spill

Configuring spill only stores Pending. The next write_page first writes payload bytes, then takes Pending and creates the sidecar. Creation failure/cancellation leaves no pending spill state in the sink. The sidecar encodes length-delimited Page messages into per-column buffers; each threshold is max(256 KiB / max(columns,1),64). A single page can overshoot, Vec clear retains capacity, and chunk descriptors keep growing. This is not a strict aggregate memory cap. (rust/lance-file/src/writer/structural.rs:47-112; rust/lance-file/src/writer/structural.rs:170-172; rust/lance-file/src/writer/structural.rs:231-243)

Finish takes all metadata/spill state, flushes and shuts down the sidecar, opens it, reads each column's chunks sequentially and reconstructs the entire page Vec for that column before serializing it. Existing metadata.pages are replaced, so enabling spill after pages have accumulated does not preserve them through this path. No local sidecar deletion occurs on success or failure. Errors after taking state do not restore it. (rust/lance-file/src/writer/structural.rs:312-340)

## Finish ordering and exact footer

All three wrappers perform the same sequence: flush buffered encoder pages; consume and finish field encoders; merge schema metadata and unload blob fields; write descriptor raw; serialize column metadata; write column offset table; write global offset table; append footer; shutdown object writer. The returned row count comes from pipeline accounting and size comes from shutdown. A never-initialized lazy writer reaches descriptor creation only after the empty flush path, then errors because schema is unknown. (rust/lance-file/src/versions/v2_1/writer.rs:152-186; rust/lance-file/src/versions/v2_2/writer.rs:152-186; rust/lance-file/src/versions/v2_3/writer.rs:152-186; rust/lance-file/src/writer/structural.rs:705-801)

Offset tables have no prefix: each entry is (position:u64 LE,length:u64 LE). The global table starts with descriptor entry0, then user globals in insertion order, even though their payloads were written earlier. Descriptor and column metadata are raw protobuf messages located by these tables; neither receives a length prefix or alignment padding here. (rust/lance-file/src/writer/structural.rs:279-309; rust/lance-file/src/writer/structural.rs:343-350)

| Bytes relative to footer start | Value |
|---|---|
| 0–7 | column metadata region start, u64 LE |
| 8–15 | column offset table start, u64 LE |
| 16–23 | global offset table start, u64 LE |
| 24–27 | number of global buffers, u32 LE |
| 28–31 | number of physical columns, u32 LE |
| 32–33 | major version 2, u16 LE |
| 34–35 | exact minor 1, 2 or 3, u16 LE |
| 36–39 | ASCII LANC |

The footer is 40 bytes, with no checksum or count-range validation in these wrappers. The three minor literals are owned by their respective concrete writer. (rust/lance-file/src/versions/v2_1/writer.rs:172-184; rust/lance-file/src/versions/v2_2/writer.rs:172-184; rust/lance-file/src/versions/v2_3/writer.rs:172-184; rust/lance-file/src/format.rs:33-33)

concat_lance_footer copies batch.data and appends an optional descriptor, per-column metadata and both offset tables before that same exact footer. It preserves supplied page/column offsets, ignores ColumnInfo.index and batch.top_level_columns, and does not check alignment, exact page grammar or buffer bounds. In mini mode the global table is empty. In self-described mode it clones the existing core Schema; unlike pipeline descriptor creation, it does not unload blobs or validate that schema. (rust/lance-file/src/writer/structural.rs:813-921; rust/lance-core/src/datatypes/schema.rs:970-975; rust/lance-file/src/versions/v2_1/writer.rs:204-224; rust/lance-file/src/versions/v2_2/writer.rs:204-224; rust/lance-file/src/versions/v2_3/writer.rs:204-224)

## Errors, ownership and change consequences

finish is mutable rather than consuming, but is not made idempotent: field encoders and metadata are taken, schema metadata is drained, footer writes can partially succeed, and no finished flag guards another call. Each public abort(&mut self) is an empty async body. It does not drop the object writer; its comment about multipart cleanup on drop is not an implementation of abort. Backend cleanup behavior must be established separately before callers rely on it. (rust/lance-file/src/writer/structural.rs:312-340; rust/lance-file/src/writer/structural.rs:725-801; rust/lance-file/src/versions/v2_1/writer.rs:152-191; rust/lance-file/src/versions/v2_2/writer.rs:152-191; rust/lance-file/src/versions/v2_3/writer.rs:152-191)

Private indexing/unwrap assumptions require schema, encoders, counts and physical columns to stay coherent. The final physical-column mismatch uses an unconditional panic; per-encoder counts use a debug assertion. No equal-field-length assertion is added. A new mechanism must preserve output count/order, address/padding correspondence and caller row accounting, and must not assume errors rewind state. (rust/lance-file/src/writer/structural.rs:546-568; rust/lance-file/src/writer/structural.rs:610-649; rust/lance-file/src/writer/structural.rs:697-701; rust/lance-file/src/writer/structural.rs:725-776)

## Local tests and usage

Four helper-level tests cover hidden child null acceptance, visible child null rejection, dictionary logical-null rejection, and sliced-parent mask alignment. The two rejection cases inspect field-name text rather than Error variants. They do not test persistence, IO, spill, abort, overflow, footer bytes or reordered batch validation. use arrow_array::RecordBatch;
