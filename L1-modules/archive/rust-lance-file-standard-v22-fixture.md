## Large mini-block framing

All23 mini-block layouts set has_large_chunk=true, num_buffers1. Metadata buffer0 stores UInt32 words; buffer1 concatenates chunks. Low4 bits encode log_num_values,0 means remaining physical values; high28 encode chunk_bytes/8-1, with2^31-byte maximum. A final full chunk can retain nonzero log: full blob chunks use8. Header fields num_levels and optional rep_size/def_size remain UInt16; only value-buffer lengths widen to UInt32. Header and every stream then pad to8 with0xFE. Outer page buffers separately pad to64 with0x48. Do not widen all fields together. The current V2_2 composition orders reject_sparse, constant, dense_u32. (rust/lance-file/src/versions/v2_2/mod.rs:119-131; rust/lance-encoding/src/encodings/logical/primitive.rs:5751-5910; rust/lance-encoding/src/encodings/physical/value.rs:83-111; rust/lance-file/test_data/exact_versions/v2_2.lance@bytes:0-500987)

Because list chunks have both level streams, widening value size moves their header from8 to10 bytes, requiring16 bytes after padding. Each list chunk therefore grows8 bytes; the first four list data buffers grow24 bytes and final grows8. Other mini-block headers still fit8 bytes. Full-batch buffer starts happen to remain identical to V2.1 because 64-byte outer padding absorbs the growth; this is an observed fixture property, not a universal promise. The V2.2 metadata arrays double in size,23 layout messages add the has_large_chunk field, and final constants remove three physical page buffers in total. Relative to V2.1, data ends192 bytes earlier, column metadata is12 bytes longer, and the entire artifact is180 bytes shorter. ## Value and level algorithms

For native width T and packed width W, FastLanes uses lanes=1024/T and order=[0,4,2,6,1,5,3,7]. Lane l,row k maps to input index order[floor(k/8)]*16+(k%8)*128+l. Its W bits occupy lane bit positions k*W..(k+1)*W, LSB first; packed native word j is stored at word index lanes*j+l. Packed payload is128*W bytes for1024 padded values. W0 has no payload; W=T still transposes. InlineBitpacking prepends W in a native-width word, with all padded decoded values zero. OutOfLineBitpacking takes W from the nested Flat metadata and packs full1024-level groups without headers; a tail n is padded/packed only if W*(1024-n)<(T-W)*n, otherwise stored raw. The decoder checks all bits and padding. ## Change impact and limits

Treat32-bit chunk words separately from16-bit rep/def fields; account for internal padding before comparing offsets. Classify a ConstantLayout by scalar presence and buffer shape, and recover type from schema. Preserve stable bytes as the oracle, even if another encoding produces equivalent values. The [decoder](../../tools/analyze-standard-v22-fixture.mjs) and [independent assembler](../../tools/verify-standard-v22-reconstruction.mjs) cover artifact content only.
