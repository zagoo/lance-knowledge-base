## Mini-block framing and count semantics

Buffer0 is a UInt16 chunk-metadata array, buffer1 concatenates chunks. Each metadata word stores log_num_values in low4 bits and chunk_bytes/8-1 in high12. Nonzero log gives2^log physical slots; log0 gives remaining physical slots. The last chunk need not use0: each full blob page has four256-value chunks whose codes all equal8. The comment in MiniBlockChunk says the final chunk should use0, but ValueEncoder permits all-full partitions with no special remainder. Do not reject valid final full chunks. V2.1 has_large_chunk is absent/false, so metadata and value sizes use UInt16. Chunk size includes internal alignment; maximum representable size is32768. ## Compression and every packed bit

FastLanes is not simple consecutive LSB packing of input values. For native width T and compressed width W, define lanes=1024/T and order=[0,4,2,6,1,5,3,7]. For lane l and row k=0..T-1, input index=order[floor(k/8)]*16+(k%8)*128+l. Pack its W bits into lane-stream position k*W, least significant bit first; packed native word j for that lane is stored at word index lanes*j+l. Native words are little-endian in this fixture. Output is128*W bytes for1024 padded values; W0 has no packed payload, W=T still applies the transpose. The decoder checks every unused padded value is zero. (rust/compression/bitpacking/src/lib.rs:4-172; rust/lance-encoding/src/encodings/physical/bitpacking.rs:44-286; rust/lance-file/test_data/exact_versions/v2_1.lance@bytes:0-501167)

InlineBitpacking prepends W as a native-width word (1/2/4 bytes here) to the packed block. id pages use widths10/11/12/12, then a raw32-bit final value. List child chunks use widths [11,12,12], [13,13,13], [13,14,14], [14,14,14], then raw32 values. Category uses inline native8 width2 plus a separate inline native16 width1 definition stream; final key is raw8 and has no def stream. Name definition chunks use inline native16 width1 and pad128 actual levels to1024 values. The final list def stream consists only of a two-byte width0 header. (rust/lance-encoding/src/encodings/physical/bitpacking.rs:44-189; rust/lance-file/test_data/exact_versions/v2_1.lance@bytes:0-498240)
