## Compressive grammar: required children versus unchecked attributes

Across V2_1/2/3, Flat, InlineBitpacking and Constant compression variants succeed without inspecting widths, optional buffer-compression descriptors, literal bytes or other fields. Variable requires offsets; OutOfLineBitpacking, Fsst, ByteStreamSplit, General, FixedSizeList and PackedStruct require values. Dictionary validates indices first, then items. Each required child is recursively validated; missing compression oneof is InvalidInput. General does not require a compression descriptor here; cardinalities, dimensions, schemes, levels and numeric bounds are not generally checked by these visitors. (rust/lance-file/src/versions/v2_1/reader.rs:18-109; rust/lance-file/src/versions/v2_2/reader.rs:18-115; rust/lance-file/src/versions/v2_3/reader.rs:20-147)

V2_1/V2_2 RLE require direct Flat values of8/16/32/64bits with data=None and direct Flat8 run lengths with data=None. They reject wrappers, 128-bit values and any present Flat.data buffer-compression descriptor, including a default descriptor. Flat.data is metadata, not a byte payload (protos/encodings_v2_1.proto:366-372). V2_3 instead recursively validates both child trees with the full grammar; it imposes no special Flat8 requirement. V2_1 rejects VariablePackedStruct outright. V2_2/V2_3 validate each packed field.value recursively and accept an empty field list at this gate. (rust/lance-file/src/versions/v2_1/reader.rs:62-107; rust/lance-file/src/versions/v2_2/reader.rs:62-113; rust/lance-file/src/versions/v2_3/reader.rs:94-145)

These are local structural acceptance checks, not proof accepted data will decode. Recursive visitors and Blob-layout nesting have no explicit local depth limit; protobuf decoder restrictions are a separate, still unqualified boundary. (rust/lance-file/src/versions/v2_1/reader.rs:26-168; rust/lance-file/src/versions/v2_2/reader.rs:26-170; rust/lance-file/src/versions/v2_3/reader.rs:28-247)

## Page-layout matrix

| Layout | V2_1 | V2_2 | V2_3 |
|---|---|---|---|
| MiniBlock | has_large_chunk must be false | must be true | must be true |
| FullZip | required value compression | same | same |
| Constant | inline_value absent; rep/def compression absent | validate optional rep/def; inline value unchecked | same as V2_2 |
| Blob | required recursively validated inner layout | same, exact2.2 grammar | same, exact2.3 grammar |
| Sparse | rejected | rejected | large-chunk and selective nested checks |
| Missing layout | InvalidInput | InvalidInput | InvalidInput |

MiniBlock checks large-chunk flag first, then optional repetition, optional definition, required value and optional dictionary encodings. This is an exact grammar boundary; selecting a newer reader does not mean it accepts the prior miniblock flag. V2_1 can read all-null ConstantLayout even though its composition page list has no constant() mechanism. Read acceptance and writer policy must be documented separately. (rust/lance-file/src/versions/v2_1/reader.rs:111-168; rust/lance-file/src/versions/v2_2/reader.rs:117-170; rust/lance-file/src/versions/v2_3/reader.rs:196-247; rust/lance-file/src/versions/v2_1/mod.rs:125-134)

V2_3 Sparse requires has_large_chunk and value_compression. Positions are validated only when Explicit; missing sets, missing oneofs and other variants pass here. Validity delegates optional positions. List layers inspect nonempty positions, explicit counts and optional validity; FixedSizeList layers inspect optional validity only. A missing structural layer arm errors, but zero layers pass. Slot totals, ordering, ranges, dimensions and actual buffers are not checked by this visitor. (rust/lance-file/src/versions/v2_3/reader.rs:149-194)

## Projection differences

V2_0 consumes a header column for every ordinary parent and then its children. Blob/packed fields are opaque. Schema-name selection computes the original whole-schema ID map before pruning, preserving original file indices. Missing mappings are silently omitted; complete schema is still retained. V2_1+ projection wrappers use the shared leaf algorithm with original schema mapping. (rust/lance-file/src/versions/v2_0/reader.rs:177-232; rust/lance-file/src/versions/v2_1/reader.rs:202-222; rust/lance-file/src/versions/v2_2/reader.rs:204-224; rust/lance-file/src/versions/v2_3/reader.rs:281-301)

For V2_0, a comparable struct's child lengths must match its own header length; the error text about children also covers header/child mismatch. For nonstruct containers, child comparisons become disabled below that node, but the returned length remains the parent header length. The shared leaf algorithm instead derives a container's length from its first child. Both reject too few indices; production helpers reject surplus indices and require equal top-level normalized lengths. (rust/lance-file/src/versions/v2_0/reader.rs:234-310; rust/lance-file/src/reader/structural.rs:278-357)

V2_0 prepare_projection accepts Full metadata after normal projection validity checks and clones metadata/projection, ignoring IO/cache. Indexed input gets structural validity errors first, then unconditional NotSupported. Its ReadProjection trait method awaits this no-IO preparation and then computes length. Accepting a V2_0 metadata index in finish_metadata_index does not imply indexed loading is usable. (rust/lance-file/src/versions/v2_0/reader.rs:150-175; rust/lance-file/src/versions/v2_0/reader.rs:312-348; rust/lance-file/src/versions/v2_0/reader.rs:384-395)

## Local tests and change surface

V2_0 test_projection_length omits production's surplus-index check. V2_1 test helper delegates the shared version, which includes that check. Neither helper is a test case. The V2_1 single grammar test places empty VariablePackedStruct under General then FullZip and checks rejection text. V2_2 rejects a nested RLE using Flat16 run lengths; V2_3 accepts the same shape. These last names mention variable width, but construct fixed-width Flat children, not a Variable node. Tests inspect grammar only, no file bytes or decompression; rejection tests do not assert error variant. No sparse validation fixture appears in the V2_3 file. (rust/lance-file/src/versions/v2_0/reader.rs:397-415; rust/lance-file/src/versions/v2_1/reader.rs:269-365; rust/lance-file/src/versions/v2_2/reader.rs:271-369; rust/lance-file/src/versions/v2_3/reader.rs:348-491)

Changing nested grammar requires visiting every location that can contain a compressive child, including dictionary indices/items, optional level encodings, packed fields and explicit sparse sets. Keep read acceptance separate from the version writer cascade and maintain all stable contracts. These readers expose no plugin registration seam or environment configuration; ordinary module/trait composition is the extension boundary.
