## Preparation and ownership

prepare_indices runs tagged admission before cloning, derives physically rewritten columns and only then decodes/uses lineage if necessary; it preserves originals for coverage comparison. Supplied decoded ledger supports external history, while this method itself does no history IO. PreparedIndices binds only optional numeric manifest version. build_manifest_prepared checks that version, repeats admission and consumes original/prepared/reuse vectors. It does not bind source dataset identity or prove caller-supplied ledger/assembly correctness. (rust/lance-table/src/transaction/manifest_build.rs:466-535; rust/lance-table/src/transaction/manifest_build.rs:593-624)

Convenience build_manifest supplies no read state; build_manifest_with_read_version prepares without ledger or settled FRI intent. External history rejection is conditional on actual rewrite decoding, not every operation on a tagged table. Normal dataset IO prepare_attempt loads current indices, and for Update with modified fields or Merge/DataReplacement loads first tagged ledger before calling preparation. This is a contextual caller excerpt, not complete retry analysis. (rust/lance-table/src/transaction/manifest_build.rs:540-590; rust/lance/src/io/commit.rs:1579-1623)

After dispatch: stable-sort fragments by ID without deduplication; prune all-tombstone base files; reject overlay order violations; validate spilled carriers. ## Failure and performance considerations

Local allocations include cloned manifest/index/fragment vectors, coverage bitmaps, name/ID maps and sorted offset Vecs. Delete uses lookup maps; selected offset updates still linearly locate original physical_rows for each target. Range conversion compares raw byte-start pointers without dereference and skips same backing by fragment ID only when both manifests opt in; it decodes all other inline data and uses copy-on-write fragments. No unsafe block is present. Integer high-water increments and several u64-to-u32 casts are unchecked. Partial Update's fallback bound is1<<24, while overlay stamping delegates its own bounds to row-version helper. (rust/lance-table/src/transaction/manifest_build.rs:82-142; rust/lance-table/src/transaction/manifest_build.rs:704-765; rust/lance-table/src/transaction/manifest_build.rs:796-948; rust/lance-table/src/transaction/manifest_build.rs:1563-1596; rust/lance-table/src/transaction/manifest_build.rs:1969-2063)

InvalidInput/NotSupported errors guard prepared version, admission/migration, base declarations, replacement layouts, offset bounds, missing overlay targets and key edits; helper errors propagate from decoding, row-version operations and validation. Restore awaits can be cancelled before returning owned state; main builder is synchronous, borrows current metadata and mutates owned candidates, with no global lock or CAS.
